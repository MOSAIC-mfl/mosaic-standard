# boundaries/ — landscape delineations

One simplified boundary per living landscape (`<CODE>.geojson`, EPSG:4326) and all of them in
`landscapes.geojson`. Provenance per landscape: [`legacy/spec/boundary_provenance.json`](../legacy/spec/boundary_provenance.json).
The full-resolution shapefiles are published as release assets of MOSAIC-mfl/catalog: `boundaries-2026-11-10`
(all landscapes; KEN-LVB is the 5-county OCHA COD-AB outline) and the earlier `boundaries-2026-10-14`.
Rebuilt locally with [`legacy/scripts/build_boundaries.py`](../legacy/scripts/build_boundaries.py).
